# Commit Convention

## 형식

```
[태그] #PO-번호 커밋 메시지
```

## 예시

```
[Feat] #PO-27 ReadingView 구현 및 Coordinator 연결
[Design] #PO-15 홈 화면 버튼 폰트 적용
[Fix] #PO-30 스캐너 카메라 권한 오류 수정
[Setting] #PO-13 프로젝트 초기 세팅
[Docs] #PO-43 Gemini API 키 설정 가이드 추가
[Remove] #PO-20 불필요한 레거시 코드 정리
```

## 태그 종류

| 태그 | 설명 |
|---|---|
| `[Feat]` | 새로운 기능 추가 |
| `[Design]` | UI/디자인 변경 (폰트, 컬러, 레이아웃 등) |
| `[Fix]` | 버그 수정 |
| `[Setting]` | 프로젝트 설정 변경 (빌드, 환경 등) |
| `[Docs]` | 문서 추가/수정 |
| `[Remove]` | 코드/파일 삭제 |
| `[Refactor]` | 기능 변경 없이 코드 구조 개선 |

## 규칙

1. 태그 뒤에 반드시 **Jira 이슈 번호** `#PO-번호`를 붙인다
2. 커밋 메시지는 한국어로 작성한다
3. 메시지는 "~구현", "~수정", "~추가" 등 명사형으로 끝낸다
